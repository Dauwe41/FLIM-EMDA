This repository contains the notebooks that were used to support the work presented in the AFM manuscript by first author Nidda Saaed, entitled: 
"Electrically Enhanced Intraperitoneal Drug Delivery Resolved by Fluorescence Lifetime Imaging Microscopy" (under review).

Two notebooks are present:
1) FLIM data analysis:
      Script to perform FLIM (Fluorescence Lifetime Imaging Microscopy) data analysis and produce depth segmentation maps of tissue samples.
2) Figure creator:
      General notebook to reproduce part of the figures shown in the manuscript (i.e. figures 3, 4, 5 & 6)

All instructions to reproduce analysis and figures are indicated within the notebook.
